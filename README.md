# Minimus — Latin adventures

Static illustrated Latin hidden-object game. HTML, CSS, ES modules and JSON. No server or build step. Progress is stored in browser localStorage.

## GitHub Pages

Publish from the `main` branch, `/ (root)` directory in Settings → Pages. All application paths are relative, so project Pages URLs are supported. Open through an HTTP server for local development.
